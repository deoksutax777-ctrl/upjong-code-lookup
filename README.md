# 업종코드 검색기

2025년 귀속 업종코드(국세청 기준경비율 자료) + 표준산업분류(11차) 연계표 기반 오프라인 검색기.

- 배포: https://deoksutax777-ctrl.github.io/upjong-code-lookup/
- 검색 대상: 업종코드 · 분류명 · 적용기준내용 · 연계 KSIC 코드명 · 세부설명 (공백 구분 AND)
- 수록: 기준경비율 1,542건 + 연계표 전용 70건(기준경비율 미고시)

## 연간 갱신

`data/` 의 CSV 2개(귀속 업종코드, 업종코드-표준산업분류 연계표)를 새 연도 파일로 교체 후:

```
python make_html.py
```

`index.html`이 재생성된다. 커밋·푸시하면 Pages 반영.
